# gymratz-plugins

Claude Code plugins by Gymratz.

```
/plugin marketplace add Gymratz/gymratz-plugins
```

| Plugin | What it does | Install |
|---|---|---|
| [Save Point](https://github.com/Gymratz/save-point) | Context, cost and cache at a glance, with retro game themes | `/plugin install save-point@gymratz-plugins` |
| [deskpal](https://github.com/Gymratz/deskpal-mod) (private) | Live Claude Code session state on a deskpal desk display | `/plugin install deskpal@gymratz-plugins` |
